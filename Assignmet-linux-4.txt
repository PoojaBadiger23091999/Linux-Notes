Task-1 - Production Backup Simulation:
--------------------------------------

Create:

production/
├── application/
├── config/
├── logs/
├── scripts/
└── data/

1. Create at least 3 files in each directory.
2. Create a compressed backup of the entire application. (using tar and zip)
3. Display the archive contents without extracting.
4. Extract it into /tmp/production_restore.
5. Verify that the complete directory structure and files are restored.

Task-2 - Configuration backup:
------------------------------
Create:

config/
├── app.conf
├── database.conf
├── nginx.conf
└── redis.conf
1. Create config_backup.tar.gz.
2. Delete the original config/ directory.
3. Restore it from the archive.


Task-3 - Add files to an existing tar archive:
----------------------------------------------

1. Create backup.tar containing file1.txt and file2.txt.
2. Create file3.txt.
3. Add file3.txt to the existing archive.
4. Verify the contents.
