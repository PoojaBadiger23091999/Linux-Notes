Directory structure in Linux:
-----------------------------
/ --> root directory
/bin --> /usr/bin --> where regular binaries are kept 
/boot --> contains operating system booting files
/dev --> device files 
/etc  --> contians application, user , system related configs
/home --> holds the personal directories of regular users
/root --> is the home directory of root user 
/lib --> /usr/lib --> holds the libraries of applications, as well as the system libraries 

/run --> run time data
